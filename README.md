# mohd-ui

A personal [shadcn/ui](https://ui.shadcn.com)-compatible component registry, built on [Base UI](https://base-ui.com) and Tailwind CSS. Components are meant to be copied into your project via the `shadcn` CLI, not installed as an npm package.

Live registry: **https://mohd-ui.m7md1alaa15.workers.dev**

## Prerequisite

These components are built for **Base UI** (`@base-ui/react`), not Radix — your project needs a Base UI–flavored shadcn setup for them to compile as-is.

## Installing components

### One-off, by URL

```bash
pnpm dlx shadcn@latest add https://mohd-ui.m7md1alaa15.workers.dev/r/sidebar.json
```

### Shorthand, via a named registry

Add this once to your project's `components.json`:

```json
{
  "registries": {
    "@mohd-ui": "https://mohd-ui.m7md1alaa15.workers.dev/r/{name}.json"
  }
}
```

Then install by name:

```bash
pnpm dlx shadcn@latest add @mohd-ui/sidebar
pnpm dlx shadcn@latest add @mohd-ui/app-sidebar
pnpm dlx shadcn@latest add @mohd-ui/toc
```

Anything an item depends on from the default shadcn registry (`button`, `separator`, `sheet`, `tooltip`, `dropdown-menu`, ...) is pulled in automatically.

## Available items

| Name | Type | Description |
|---|---|---|
| `sidebar` | `registry:ui` | Resizable, collapsible sidebar with drag-to-resize, a mobile drawer, and keyboard shortcut toggling. |
| `app-sidebar` | `registry:block` | Worked example composing `sidebar`: grouped nav, icon-collapsed rail, theme toggle, account menu. Copy it and swap in your own data. |
| `toc` | `registry:ui` | Responsive table of contents with active-heading tracking, mobile dialog, deep links, and RTL support. |
| `toc-demo` | `registry:block` | Worked example showing `toc` tracking document sections. |

Whenever `registry.json` or any file it references changes, redeploy — `public/r/*.json` is a build artifact regenerated by `pnpm registry:build`, not something to hand-edit, and consumers always pull whatever's currently live (there's no versioning/pinning yet).
